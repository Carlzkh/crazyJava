```

├── controller

├── repository
│   └── UserRepository.java          ← 数据访问
├── mapper

├── entity
│   └── User.java                    ← 实体类
├── common
│   ├── Result.java                  ← 统一返回
```

### 3.2 各层职责

| 层级 | 职责 | 注解 |
| :--- | :--- | :--- |
| Controller | 接收 HTTP 请求，返回 JSON | @RestController |
| Service | 业务逻辑（校验、计算、调用 Repository） | @Service |
| Repository | 数据存取（调用 Mapper） | @Repository |
| Mapper | SQL 执行 | @Mapper |

### 3.3 Controller 示例

```java
@Slf4j
@RestController
@RequestMapping("/users")
public class UserController {

    @Autowired
    private UserService userService;

    @GetMapping
    public Result<List<User>> users() {
        log.info("查询用户列表");
        List<User> list = userService.getUserList();
        return Result.success(list);
    }
}
```

## 5. CRUD 接口开发

### 5.1 Controller 完整示例

```java
@Slf4j
@RestController
@RequestMapping("/api/v1/users")
public class UserController {

    @Autowired
    private UserService userService;

    // 查询所有
    @GetMapping
    public Result<List<User>> users() {
        return Result.success(userService.getUserList());
    }

    // 根据 ID 查询
    @GetMapping("/{id}")
    public Result<User> getUserById(@PathVariable Long id) {
        return Result.success(userService.getUserById(id));
    }

    // 新增
    @PostMapping
    public Result<User> createUser(@Valid @RequestBody User user) {
        return Result.success("用户创建成功", userService.createUser(user));
    }

    // 更新
    @PutMapping("/{id}")
    public Result<User> updateUser(@PathVariable Long id, @Valid @RequestBody User user) {
        return Result.success("用户更新成功", userService.updateUser(id, user));
    }

    // 删除
    @DeleteMapping("/{id}")
    public Result<Void> deleteUser(@PathVariable Long id) {
        userService.deleteUserById(id);
        return Result.success("用户删除成功", null);
    }

    // 批量删除
    @DeleteMapping("/batch")
    public Result<Integer> deleteUsersBatch(@RequestBody List<Long> ids) {
        int count = userService.deleteUsersByIds(ids);
        return Result.success("成功删除 " + count + " 个用户", count);
    }
}
```

### 5.2 Mapper XML 完整示例

```xml
<?xml version="1.0" encoding="UTF-8" ?>
<!DOCTYPE mapper PUBLIC "-//mybatis.org//DTD Mapper 3.0//EN"
        "https://mybatis.org/dtd/mybatis-3-mapper.dtd">

<mapper namespace="com.example.crazyjava.mapper.UserMapper">

    <select id="findAll" resultType="com.example.crazyjava.entity.User">
        SELECT * FROM user ORDER BY id ASC
    </select>

    <select id="findById" resultType="com.example.crazyjava.entity.User">
        SELECT * FROM user WHERE id = #{id}
    </select>

    <select id="searchUsers" resultType="com.example.crazyjava.entity.User">
        SELECT * FROM user
        <where>
            <if test="name != null and name != ''">
                AND name LIKE CONCAT('%', #{name}, '%')
            </if>
            <if test="minAge != null">
                AND age &gt;= #{minAge}
            </if>
            <if test="maxAge != null">
                AND age &lt;= #{maxAge}
            </if>
            <if test="gender != null">
                AND gender = #{gender}
            </if>
            <if test="startDate != null and startDate != ''">
                AND create_time &gt;= #{startDate}
            </if>
            <if test="endDate != null and endDate != ''">
                AND create_time &lt;= #{endDate}
            </if>
        </where>
        ORDER BY id ASC
    </select>

    <insert id="insert" useGeneratedKeys="true" keyProperty="id">
        INSERT INTO user(name, age, gender, create_time, update_time)
        VALUES(#{name}, #{age}, #{gender}, NOW(), NOW())
    </insert>

    <update id="update">
        UPDATE user
        <set>
            <if test="name != null and name != ''">
                name = #{name},
            </if>
            <if test="age != null">
                age = #{age},
            </if>
            <if test="gender != null">
                gender = #{gender},
            </if>
        </set>
        WHERE id = #{id}
    </update>

    <delete id="deleteById">
        DELETE FROM user WHERE id = #{id}
    </delete>

    <delete id="deleteByIds">
        DELETE FROM user WHERE id IN
        <foreach collection="ids" item="id" open="(" close=")" separator=",">
            #{id}
        </foreach>
    </delete>

</mapper>
```

## 7. MyBatis XML 与动态 SQL

### 7.1 核心标签

| 标签 | 作用 |
| :--- | :--- |
| `<where>` | 自动处理 WHERE 和 AND 拼接 |
| `<if>` | 条件判断，动态拼接 SQL |
| `<set>` | 动态生成 SET 子句，自动去掉多余逗号 |
| `<foreach>` | 遍历集合，生成 IN (...) |
| `&gt;` / `&lt;` | XML 转义符，表示 > 和 < |

### 7.2 动态 SQL 示例

```xml
<select id="searchUsers" resultType="com.example.crazyjava.entity.User">
    SELECT * FROM user
    <where>
        <if test="name != null and name != ''">
            AND name LIKE CONCAT('%', #{name}, '%')
        </if>
        <if test="minAge != null">
            AND age &gt;= #{minAge}
        </if>
    </where>
</select>
```

## 8. 统一异常处理

### 8.1 统一返回类

```java
@Data
public class Result<T> {
    private Integer code;
    private String msg;
    private T data;

    public static <T> Result<T> success(T data) {
        Result<T> result = new Result<>();
        result.setCode(ResultCodeEnum.SUCCESS.getCode());
        result.setMsg(ResultCodeEnum.SUCCESS.getMsg());
        result.setData(data);
        return result;
    }

    public static <T> Result<T> error(ResultCodeEnum resultCodeEnum) {
        Result<T> result = new Result<>();
        result.setCode(resultCodeEnum.getCode());
        result.setMsg(resultCodeEnum.getMsg());
        return result;
    }
}
```

### 8.2 错误码枚举

```java
@Getter
@AllArgsConstructor
public enum ResultCodeEnum {
    SUCCESS(20000, "操作成功"),
    PARAM_IS_INVALID(40000, "参数无效"),
    USER_NOT_FOUND(60000, "用户不存在"),
    USER_DELETE_FAILED(60001, "删除用户失败"),
    SYSTEM_ERROR(50000, "系统内部错误，请稍后重试");

    private final Integer code;
    private final String msg;
}
```

### 8.3 自定义业务异常

```java
@Getter
public class BusinessException extends RuntimeException {
    private final Integer code;
    private final String msg;

    public BusinessException(ResultCodeEnum resultCodeEnum) {
        super(resultCodeEnum.getMsg());
        this.code = resultCodeEnum.getCode();
        this.msg = resultCodeEnum.getMsg();
    }

    public BusinessException(Integer code, String msg) {
        super(msg);
        this.code = code;
        this.msg = msg;
    }
}
```

### 8.4 全局异常处理器

```java
@Slf4j
@RestControllerAdvice
public class GlobalExceptionHandler {

    @ExceptionHandler(BusinessException.class)
    public Result<Void> handleBusinessException(BusinessException e) {
        log.warn("业务异常: code={}, msg={}", e.getCode(), e.getMsg());
        return Result.error(e.getCode(), e.getMsg());
    }

    @ExceptionHandler(MethodArgumentNotValidException.class)
    @ResponseStatus(HttpStatus.BAD_REQUEST)
    public Result<Void> handleValidationException(MethodArgumentNotValidException e) {
        FieldError fieldError = e.getBindingResult().getFieldError();
        String errorMsg = fieldError != null ? fieldError.getDefaultMessage() : "参数校验失败";
        return Result.error(40000, errorMsg);
    }

    @ExceptionHandler(Exception.class)
    @ResponseStatus(HttpStatus.INTERNAL_SERVER_ERROR)
    public Result<Void> handleException(Exception e) {
        log.error("系统异常: {}", e.getMessage(), e);
        return Result.error(ResultCodeEnum.SYSTEM_ERROR);
    }
}
```

## 9. AOP 统一日志

### 9.1 切面类

```java
@Slf4j
@Aspect
@Component
public class LogAspect {

    @Pointcut("execution(* com.example.crazyjava.controller..*.*(..))")
    public void controllerMethod() {}

    @Around("controllerMethod()")
    public Object around(ProceedingJoinPoint joinPoint) throws Throwable {
        long startTime = System.currentTimeMillis();

        ServletRequestAttributes attributes = (ServletRequestAttributes) RequestContextHolder.getRequestAttributes();
        HttpServletRequest request = attributes.getRequest();

        log.info("========== 请求开始 ==========");
        log.info("URL: {}", request.getRequestURL());
        log.info("Method: {}", request.getMethod());
        log.info("IP: {}", request.getRemoteAddr());
        log.info("Params: {}", JSON.toJSONString(request.getParameterMap()));

        Object result = joinPoint.proceed();

        long costTime = System.currentTimeMillis() - startTime;
        log.info("Response: {}", JSON.toJSONString(result));
        log.info("耗时: {} ms", costTime);
        log.info("========== 请求结束 ==========");

        return result;
    }
}
```

```java
@ExtendWith(MockitoExtension.class)
class UserServiceTest {

    @Mock
    private UserRepository userRepository;

    @InjectMocks
    private UserService userService;

    @Test
    void getUserById_shouldReturnUser_whenIdExists() {
        Long userId = 1L;
        User mockUser = new User();
        mockUser.setId(userId);
        mockUser.setName("Alice");

        when(userRepository.findById(userId)).thenReturn(mockUser);

        User result = userService.getUserById(userId);

        assertNotNull(result);
        assertEquals("Alice", result.getName());
        verify(userRepository, times(1)).findById(userId);
    }

    @Test
    void getUserById_shouldThrowBusinessException_whenUserNotFound() {
        when(userRepository.findById(999L)).thenReturn(null);

        BusinessException exception = assertThrows(BusinessException.class, () -> {
            userService.getUserById(999L);
        });

        assertEquals(ResultCodeEnum.USER_NOT_FOUND.getCode(), exception.getCode());
    }
}
```

## 16. 问题与解决汇总

### 16.1 依赖版本问题

| 问题 | 原因 | 解决方案 |
| :--- | :--- | :--- |
| Could not find artifact ... pom:unknown | 没有指定版本号，且没有继承 Parent | 显式指定版本号，或加上 spring-boot-starter-parent |

## 17. 经验总结

1. **依赖管理**：继承 spring-boot-starter-parent 后，不要重复写版本号，但不在 Parent 管理范围内的依赖需要显式指定。
2. **多环境配置**：application-{profile}.properties 命名规则 + --spring.profiles.active 激活。
3. **MyBatis 动态 SQL**：<where> + <if> + <foreach> 是核心三件套。
4. **异常处理**：业务异常用 BusinessException，系统异常用全局兜底。
5. **打包部署**：spring-boot-maven-plugin 是生成可执行 jar 的关键。
6. **日志冲突**：SLF4J + Logback 版本必须统一，让 SpringBoot 自动管理最省心。
7. **权限最小化**：生产环境使用独立数据库用户，只授予必要权限。
